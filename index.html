IT Helpdesk & Network Support

Kỹ thuật viên IT trẻ tại TP. Hồ Chí Minh, thành thạo triển khai — bảo trì mạng nội bộ và hỗ trợ người dùng. Có nền tảng lập trình web (HTML, CSS, JS, PHP) để chủ động viết công cụ tự động hóa cho công việc support.

Giới thiệu

Tôi đến với IT từ những việc rất đời: sửa máy tính cho người thân, kéo dây mạng cho quán cà phê bạn bè — và biến thói quen "ai gì hỏng cũng gọi mình" thành hướng nghề nghiệp: Helpdesk & Network Support.

Điểm mạnh của tôi là sự kết hợp hiếm có: xử lý sự cố mạng — hệ thống chắc tay, và biết lập trình web để viết tool tự động hóa công việc support (theo dõi uptime, trang nội bộ, quản lý ticket). Tôi kiên nhẫn với người dùng, ghi chép rõ ràng, luôn giữ thái độ dễ chịu kể cả khi cả tầng mất mạng 🌱

Ngoài công việc, tôi là người kỷ luật và giàu năng lượng — đam mê mô tô, bóng đá và văn hóa anime.

Kỹ năng

🌐 Network

  • TCP/IP, DNS, DHCP, subnetting
  • LAN/WAN, VLAN, cấu hình switch & router (Cisco, MikroTik)
  • Đi cáp UTP/cáp quang, bấm head, test mạng
  • Giám sát uptime, WiFi survey & tối ưu

🛠️ Helpdesk & Systems

  • Windows 10/11, Windows Server cơ bản
  • Active Directory, Office 365, chia sẻ máy in/thiết bị
  • Triển khai máy cho nhân viên, remote support
  • Quy trình ticket, tài liệu hóa lỗi rõ ràng

💻 Web & Automation

  • HTML, CSS, JavaScript — dựng trang nội bộ, dashboard
  • PHP & Google Apps Script — tool tự động hóa
  • Git & GitHub — quản lý phiên bản, GitHub Pages
